# Simulation d'une chaîne de blocs reliés par des empreintes cryptographiques (SHA-256)

## Sujet
Création d'une simulation pédagogique montrant comment les blocs d'une blockchain sont reliés cryptographiquement via le hachage SHA-256 et comment toute modification altère l'intégrité de la chaîne.

## Résultat attendu
Un script de simulation fonctionnel (`simulation_blockchain.py`) accompagné d'un guide explicatif détaillant le mécanisme de chaînage des empreintes, la détection d'altération et l'effet avalanche.
